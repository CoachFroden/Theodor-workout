# Theodor Workout

Mobil-først PWA for Theodors styrkeprogram fra PT.

- 14 aktive øvelser
- redigerbar vekt, sett og repetisjoner
- økthistorikk og progresjon lagret lokalt
- bibliotek med de 23 øvelsene fra prøvetimen
- offline-støtte og hjemskjermoppsett på iPhone

Programdata er lagt inn fra PT-arkene og skal brukes som startpunkt, ikke som automatisk anbefaling om å øke belastning.
